## 4. Что нужно для завершения переноса содержимого

1. Разрешить доступ к `cloudrepairs.ru` в настройках сети облачной среды
   (Network access → Allowed domains) или запустить `npm run import:original`
   на компьютере, где сайт открывается.
2. Перенести тексты из `import/<страница>/content.md` в `src/content/*.ts`,
   а изображения — в `public/media/<страница>/`.
3. Сверить формулировки главной страницы, помеченные «пересказ».
4. Заменить временный логотип (`src/components/brand/Logo.tsx`,
   `public/favicon.svg`) и при необходимости поправить цвета
   (`src/styles/tokens.css`).
5. Указать оригинальные `title` и `description` в `src/seo.ts`.
